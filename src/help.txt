cho — a small, type-aware text processor for the command line

Usage: cho [OPTIONS] 'PROGRAM'

Common recipes:
  Pick fields             cho '(p $1 $3)'
  Skip empty records      cho '(f (not (s/empty? $0)))'
  Filter numbers          cho '(f (> $2 20))'
  Match a field           cho '(f (~ $1 /^api-/))'
  Match the whole record  cho '(f (~ /ERROR|WARN/))'
  Transform one value     cho '(s/upper $1)'
  Join values             cho '(p (s/join "," $1 $2))'
  Replace text            cho '(p (s/replace-all $1 "-" "_"))'
  Use a fallback          cho '(p (default $3 "unknown"))'
  Read CSV with a header  cho --csv -s '(p $1 $3)'
  Read TSV                cho --tsv '(p $1 $2)'
  Run without input       cho -n '(p (dt/now))'
  Call one function       cho -c s/upper

Input and options:
  -F SEPARATOR       split fields using this regular expression
  -FSEPARATOR        short form of -F SEPARATOR
  --csv              parse CSV records, including quoted values
  --tsv              split fields on tabs
  -s, --skip-header  skip the first CSV or TSV record
  -n, --no-input     do not read input; run once with an empty record
  -c, --call         call FUNCTION with $0 followed by ARG values
  -h, --help         print help
  -V, --version      print version

  PROGRAM runs once per input record. Whitespace splits fields by default.
  $0 is the complete record; $1, $2, ... are fields. NR is the record number;
  NF is the field count. Missing fields are empty strings. With --skip-header,
  the first data record keeps its input position and therefore has NR 2.
  With --no-input, $0 is empty, NR is 1, and NF is 0.
  With --call, $0 is always the first function argument. Following arguments
  named $0, $1, ... are field references; all others are Strings and become the
  second and later function arguments. You cannot pass NR or NF as record values;
  both are treated as Strings. Quote field references such as $1 from the shell.
  Options must precede --call because every following argument belongs to the
  call. Use the regular program syntax to select another primary input.
  Examples: printf 'hoge\n' | cho -c s/upper
            printf 'foo-bar\n' | cho -c s/replace - _
  The -F separator must be a valid regular expression. It must not match an
  empty string.

Program forms:
  (print VALUE ...)                         print values separated by spaces
  (p VALUE ...)                             short form of print
  (filter BOOLEAN)                          continue only when true
  (f BOOLEAN)                               short form of filter

  A single top-level value is printed automatically. It may follow filters.
  Use print to output multiple values separated by spaces. Do not mix an
  automatic top-level value with print or place multiple values at the top level.
  A program containing only filters implicitly prints $0 after they pass.
  An empty program also prints $0. Any explicit print disables implicit output.

Literals and fields:
  $0, $1, ...                    complete record or field
  $..3, $3.., $2..4             inclusive field ranges, preserving separators
  NR, NF                         record number or field count
  "text", 12, 3.5                String or Number
  true, false                    Boolean
  (field NUMBER) -> STRING                  get a field by its computed number
  (fields START END) -> STRING              get a computed inclusive field range
  (fields-from START) -> STRING             get fields from a computed position through the record end
  (fields-to END) -> STRING                 get fields from the record start through a computed position

  An omitted range bound extends to that edge of the complete record, including
  leading or trailing separators. An end beyond NF stops at NF. A start beyond
  NF is empty.
  field accepts a non-negative whole number; 0 selects the complete record.
  fields, fields-from, and fields-to require positive whole-number bounds;
  fields also requires START to be less than or equal to END.
  Field ranges are unavailable with --csv because CSV fields are decoded.

Numbers:
  (+ NUMBER NUMBER) -> NUMBER               add
  (- NUMBER NUMBER) -> NUMBER               subtract
  (* NUMBER NUMBER) -> NUMBER               multiply
  (/ NUMBER NUMBER) -> NUMBER               divide
  (% NUMBER NUMBER) -> NUMBER               remainder
  (n/trunc NUMBER) -> NUMBER                discard fractional digits toward zero
  (n/floor NUMBER) -> NUMBER                round down toward negative infinity
  (n/ceil NUMBER) -> NUMBER                 round up toward positive infinity
  (n/round NUMBER) -> NUMBER                round to nearest, halves away from zero
  (n/abs NUMBER) -> NUMBER                  absolute value
  (n/fixed NUMBER DIGITS) -> STRING         format with 0 to 100 fractional digits
  (n/min NUMBER NUMBER ...) -> NUMBER       return the smallest number
  (n/max NUMBER NUMBER ...) -> NUMBER       return the largest number
  (n/clamp NUMBER MIN MAX) -> NUMBER        limit a number to an inclusive range
  (> NUMBER NUMBER) -> BOOLEAN              greater than
  (>= NUMBER NUMBER) -> BOOLEAN             greater than or equal
  (< NUMBER NUMBER) -> BOOLEAN              less than
  (<= NUMBER NUMBER) -> BOOLEAN             less than or equal
  (= NUMBER NUMBER) -> BOOLEAN              equal
  (!= NUMBER NUMBER) -> BOOLEAN             not equal

  Number uses IEEE 754 double precision. Integers outside the safe range from
  -(2^53 - 1) through 2^53 - 1 may lose precision or compare equal. Compare
  integer identifiers as strings with s/=. Decimal arithmetic may round.

Strings:
  (str VALUE ...) -> STRING                    concatenate values
  (s/join SEPARATOR VALUE ...) -> STRING       join values
  (s/repeat VALUE COUNT) -> STRING             repeat a value
  (s/replace VALUE FROM TO) -> STRING          replace the first literal match
  (s/replace-all VALUE FROM TO) -> STRING      replace all literal matches
  (s/part VALUE DELIMITER POSITION) -> STRING  take a 1-based literal-delimited part
  (s/before VALUE DELIMITER) -> STRING         take text before the first literal delimiter
  (s/after VALUE DELIMITER) -> STRING          take text after the first literal delimiter
  (s/slice VALUE START [LENGTH]) -> STRING     take Unicode characters from a 1-based start
  (s/lpad VALUE WIDTH [FILL]) -> STRING        pad the left side to a Unicode character width
  (s/rpad VALUE WIDTH [FILL]) -> STRING        pad the right side to a Unicode character width
  (s/count VALUE) -> NUMBER                    count Unicode characters
  (s/empty? VALUE) -> BOOLEAN                  test whether a string is empty
  (s/escape VALUE) -> STRING                   escape tabs, newlines, and backslashes
  (s/dquote VALUE) -> STRING                   stringify and wrap in escaped double quotes
  (dq VALUE) -> STRING                         short form of s/dquote
  (s/squote VALUE) -> STRING                   stringify and wrap in escaped single quotes
  (sq VALUE) -> STRING                         short form of s/squote
  (s/unquote VALUE) -> STRING                  remove matching quotes and decode backslash escapes
  (shq VALUE) -> STRING                        stringify and quote as one shell-safe argument
  (s/lower VALUE) -> STRING                    lowercase
  (s/upper VALUE) -> STRING                    uppercase
  (s/reverse VALUE) -> STRING                  reverse Unicode characters
  (s/trim VALUE) -> STRING                     remove Unicode whitespace from both ends
  (s/trim VALUE PREFIX SUFFIX) -> STRING       remove one exact prefix and suffix
  (s/ltrim VALUE) -> STRING                    remove Unicode whitespace from the left
  (s/ltrim VALUE PREFIX) -> STRING             remove one exact prefix
  (s/rtrim VALUE) -> STRING                    remove Unicode whitespace from the right
  (s/rtrim VALUE SUFFIX) -> STRING             remove one exact suffix
  (s/starts-with? VALUE PREFIX) -> BOOLEAN     test a prefix
  (s/ends-with? VALUE SUFFIX) -> BOOLEAN       test a suffix
  (s/contains? VALUE NEEDLE) -> BOOLEAN        test a substring
  (s/> VALUE VALUE) -> BOOLEAN                 greater than
  (s/>= VALUE VALUE) -> BOOLEAN                greater than or equal
  (s/< VALUE VALUE) -> BOOLEAN                 less than
  (s/<= VALUE VALUE) -> BOOLEAN                less than or equal
  (s/= VALUE VALUE) -> BOOLEAN                 equal
  (s/!= VALUE VALUE) -> BOOLEAN                not equal

  String functions render VALUE arguments with their default representation
  before processing. The s/ prefix therefore explicitly selects string
  semantics for transformations, tests, and comparisons of any value.

  s/part preserves empty parts. If no delimiter is found, position 1 returns
  the complete value; a missing position returns an empty string. DELIMITER
  must not be empty.
  s/before and s/after use the first delimiter and preserve the complete value
  on the other side. Without a delimiter, s/before returns the complete value
  and s/after returns empty. DELIMITER must not be empty.
  s/slice without LENGTH returns through the end. An excessive LENGTH stops at
  the end; an excessive START returns empty. START must be positive and LENGTH
  must be non-negative. Both must be whole numbers.
  s/lpad and s/rpad count Unicode characters, not terminal display columns.
  WIDTH must be a non-negative whole number. FILL defaults to one space and
  must be exactly one Unicode character. Values already at least WIDTH long are
  unchanged.
  s/dquote and s/squote escape the enclosing quote, backslashes, tabs, and
  line breaks with a backslash.
  With explicit affixes, s/trim removes PREFIX and then SUFFIX independently;
  s/ltrim and s/rtrim remove one exact affix. Each affix is removed at most
  once. Empty or absent affixes leave that end unchanged.
  s/unquote reverses s/dquote and s/squote. Unquoted values are unchanged;
  mismatched quotes, incomplete escapes, and unsupported escapes are errors.
  shq produces POSIX shell-safe quoting for exactly one argument. Unlike dq,
  it prevents parameter expansion, command substitution, and globbing.
  An empty FROM inserts TO at the start with s/replace, or at every character
  boundary with s/replace-all, like awk sub("", ...) and gsub("", ...).
  Empty prefixes, suffixes, and needles match every string, including empty.
  Example: cho --no-input '(p (dq (s/trim "  hello  ")))'

Paths:
  (path/name STRING) -> STRING              extract the final path component
  (path/stem STRING) -> STRING              extract the final component without its extension
  (path/ext STRING) -> STRING               extract the extension without its dot or an empty string
  (path/dir STRING) -> STRING               extract the directory or an empty string

  Path functions inspect strings lexically as Unix paths. Only / is a
  separator; the filesystem, environment variables, ~, ., and .. are not
  resolved. Trailing separators are ignored when extracting components.

Boolean functions:
  (not BOOLEAN) -> BOOLEAN                  negate

Special forms (evaluate only the values they need):
  (if BOOLEAN VALUE VALUE) -> VALUE         select one value lazily
  (default VALUE FALLBACK) -> VALUE         use a fallback when the value is empty or errors
  (and BOOLEAN BOOLEAN ...) -> BOOLEAN      stop at the first false value
  (or BOOLEAN BOOLEAN ...) -> BOOLEAN       stop at the first true value

Regular expressions:
  (reg /PATTERN/) -> BOOLEAN                              match a regular expression
  (reg VALUE /PATTERN/) -> BOOLEAN                        match a regular expression
  (~ /PATTERN/) -> BOOLEAN                                short form of reg
  (~ VALUE /PATTERN/) -> BOOLEAN                          short form of reg
  (re/replace VALUE /PATTERN/ REPLACEMENT) -> STRING      replace the first regular-expression match
  (re/replace-all VALUE /PATTERN/ REPLACEMENT) -> STRING  replace all regular-expression matches
  (re/part VALUE /PATTERN/ POSITION) -> STRING            take a 1-based regular-expression-delimited part

  Regex literals preserve backslashes; escape only a literal / as \/:
    (~ $1 /^\d+$/)     (~ $1 /^foo\/bar$/)
  Quoted patterns are also accepted and require doubled backslashes:
    (reg $1 "^\\d+$")     (re/replace $1 "\\d+" "X")
  Replacement expands $0, $1, and ${name}; write $$ for a literal dollar sign.
  re/part preserves empty parts. If the pattern does not match, position 1
  returns the complete value; a missing position returns an empty string.
  In replacements, empty and zero-width matches insert text, following awk behavior.
  The -F pattern is passed directly: cho -F '\s+' '(p $1)'
  Example: cho --no-input '(p (re/replace "id=42" /(?P<n>\d+)/ "[${n}]"))'

DateTime and Duration:
  (dt/unix NUMBER) -> DATETIME                 convert Unix seconds
  (dt/to-unix DATETIME) -> NUMBER              convert a datetime to Unix seconds
  (dt/fmt DATETIME STRING) -> STRING           format in UTC
  (dt/fmt DATETIME STRING TIMEZONE) -> STRING  format in the specified timezone
  (dt/now) -> DATETIME                         current UTC time at second precision
  (dt/floor-s DATETIME) -> DATETIME            floor to a local or UTC second
  (dt/floor-s DATETIME TIMEZONE) -> DATETIME   floor to a local or UTC second
  (dt/floor-m DATETIME) -> DATETIME            floor to a local or UTC minute
  (dt/floor-m DATETIME TIMEZONE) -> DATETIME   floor to a local or UTC minute
  (dt/floor-h DATETIME) -> DATETIME            floor to a local or UTC hour
  (dt/floor-h DATETIME TIMEZONE) -> DATETIME   floor to a local or UTC hour
  (dt/floor-d DATETIME) -> DATETIME            floor to a local or UTC calendar day
  (dt/floor-d DATETIME TIMEZONE) -> DATETIME   floor to a local or UTC calendar day
  (dt/add DATETIME DURATION) -> DATETIME       add a duration
  (dt/sub DATETIME DURATION) -> DATETIME       subtract a duration
  (dt/diff DATETIME DATETIME) -> DURATION      subtract the right datetime from the left
  (du/s NUMBER) -> DURATION                    convert seconds to a duration
  (du/ms NUMBER) -> DURATION                   convert milliseconds to a duration
  (du/m NUMBER) -> DURATION                    convert minutes to a duration
  (du/h NUMBER) -> DURATION                    convert hours to a duration
  (du/d NUMBER) -> DURATION                    convert fixed 24-hour days to a duration
  (du/to-ms DURATION) -> NUMBER                convert a duration to milliseconds
  (du/to-s DURATION) -> NUMBER                 convert a duration to seconds
  (du/to-m DURATION) -> NUMBER                 convert a duration to minutes
  (du/to-h DURATION) -> NUMBER                 convert a duration to hours
  (du/to-d DURATION) -> NUMBER                 convert a duration to fixed 24-hour days
  (dt/> DATETIME DATETIME) -> BOOLEAN          greater than
  (dt/>= DATETIME DATETIME) -> BOOLEAN         greater than or equal
  (dt/< DATETIME DATETIME) -> BOOLEAN          less than
  (dt/<= DATETIME DATETIME) -> BOOLEAN         less than or equal
  (dt/= DATETIME DATETIME) -> BOOLEAN          equal
  (dt/!= DATETIME DATETIME) -> BOOLEAN         not equal

  DateTime input must be RFC 3339 with an offset or Z. DateTime renders in UTC;
  Duration renders as seconds. TIMEZONE is an IANA name such as Asia/Tokyo or a
  fixed offset such as +09:00. Without TIMEZONE, dt/floor-* uses UTC boundaries.
  dt/unix accepts only whole Unix seconds within the supported DateTime range.
  At DST changes, floor chooses the latest matching boundary not after the input;
  if that local boundary does not exist, it uses the first local time after it.

URLs:
  (url/scheme URL) -> STRING                extract the scheme
  (url/host URL) -> STRING                  extract the host
  (url/port URL) -> STRING                  extract the port or an empty string
  (url/path URL) -> STRING                  extract the path
  (url/query URL) -> STRING                 extract the query or an empty string
  (url/fragment URL) -> STRING              extract the fragment or an empty string
  (url/query-get URL STRING) -> STRING      return the first decoded value or an empty string
  (url/query-has? URL STRING) -> BOOLEAN    test whether a decoded query name exists
  (url/encode STRING) -> STRING             encode an RFC 3986 component
  (url/decode STRING) -> STRING             percent-decode a component

  Extracted components preserve percent encoding. Query operations use form
  semantics (+ is space), decode names and values, and use the first duplicate.
  url/encode uses uppercase escapes. url/decode decodes only %XX and leaves +
  unchanged. Invalid URLs, escapes, or UTF-8 are errors.

  (semver/< SEMVER SEMVER) -> BOOLEAN       less than
  (semver/<= SEMVER SEMVER) -> BOOLEAN      less than or equal
  (semver/= SEMVER SEMVER) -> BOOLEAN       equal
  (semver/!= SEMVER SEMVER) -> BOOLEAN      not equal
  (semver/major SEMVER) -> NUMBER           return the major version
  (semver/minor SEMVER) -> NUMBER           return the minor version
  (semver/patch SEMVER) -> NUMBER           return the patch version
  (semver/prerelease SEMVER) -> STRING      return prerelease text or an empty string
  (semver/build SEMVER) -> STRING           return build metadata or an empty string

Types and errors:
  String      fields and quoted literals    DateTime  RFC 3339 timestamps
  Number      numeric literals, NR, NF       Duration  signed seconds
  Boolean     true, false, predicates        IpAddr    IPv4 or IPv6
  Cidr        IPv4 or IPv6 networks          Url       absolute URLs
  SemVer      MAJOR.MINOR.PATCH versions

  Functions convert Strings when they require another type. Failed conversion
  reports the record, function, and argument number. Boolean values never
  convert implicitly from strings or numbers. Numeric arithmetic is binary;
  division by zero and non-finite results are errors.

Composition:
  A VALUE can be a literal, field, function call, or special form. Values nest
  anywhere a VALUE is accepted. Multiple program forms run left to right; a
  failed filter skips the rest of that record. Multiple filters therefore act
  like AND. If the program is empty or contains only filters,
  cho implicitly prints $0 after the filters pass.
  Functions with one primary input put it first, followed by configuration.
  Variadic functions such as str and s/join have no single primary input.

  (-> VALUE STEP ...) -> VALUE              insert a value as each step's first argument
  (->> VALUE STEP ...) -> VALUE             insert a value as each step's last argument

    (-> $1 (dt/add (du/s 10)))
      is (dt/add $1 (du/s 10))

    (-> $1 (dt/fmt "%Y/%m/%d"))
      is (dt/fmt $1 "%Y/%m/%d")

    (-> $1 s/trim (s/replace "-" "_") s/upper)

More examples:
  Extract a log message while preserving its original whitespace:
    printf '2026-08-24 INFO service started successfully\n' | cho '(p $3..)'

  Format an RFC 3339 timestamp in Tokyo time:
    cho '(p (dt/fmt $1 "%Y-%m-%d %H:%M" "Asia/Tokyo"))'

  Join transformed fields, with a fallback for a missing third field:
    cho '(p (s/join ":" (s/upper $1) (default $3 "UNKNOWN")))'
